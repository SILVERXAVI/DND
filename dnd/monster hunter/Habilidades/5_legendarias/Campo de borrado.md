## Campo de Borrado
_Don, Legendario_
**Tipo:** Emisor

**Descripción:** Este Don permite al usuario generar una gran onda de energía en forma de cúpula que desactiva los Dones de cualquiera dentro de su alcance. Todos los Dones (excepto las mutaciones) quedan inactivos dentro de este campo, lo que proporciona una importante ventaja táctica. El usuario también puede crear una burbuja controlada más pequeña dentro del campo que mantiene activos sus propios Dones y los de sus aliados.

**Debilidades:** Este Don requiere que el usuario mantenga la concentración. Cada vez que recibe daño, debe realizar una prueba de Constitución CD 13. Si pierde la concentración y cualquier distracción interrumpe el campo de energía, perderá el control y el Don se desactivará. El usuario también debe permanecer dentro de los límites del campo para mantener sus efectos y no puede moverse ni realizar acciones.

**Campo de Borrado:** Como acción, el usuario puede crear un Campo de Borrado con un radio de 60 metros (200 pies), con una duración máxima de 5 minutos. Dentro de este radio, todas las peculiaridades se desactivan, y el usuario puede mantener una burbuja de 30 metros de radio que permite a las personas que elija conservar sus peculiaridades. Si salen de este radio, pierden sus peculiaridades hasta que vuelvan a entrar en él.
