
dependiendo la clase podrá usar distinta arma

las clases constaran de: 
- vida, 
- competencia con armas y armadura, 
- herramientas, 
- tiradas de salvación 
- habilidades
todo esto junto con la característica principal de la clase: 
el artificiero la mecanica
el bárbaro tiene ira
el bardo la inspiracion
el brujo los pactos
el clerigo la curacion 
el druida la transformacion
el guardabosques con mejoras para la distancia
el hechicero con versiones de mejoras dependiendo el alma
el luchador tiene mas hazañas
el mago la capacidad de aprender hechizos en cualquier momento
el monje con multiple ataques desarmado
el paladin con sus juramentos
el picaro con el sigilo
etc

las clases de mago (con capacidad de hacer hechizos) podran aprender un nuevo hechizo cada vez que suban de nivel, y con cada hazaña que consigan (cada 4 niveles) podra tener un hechizo de nivel superior

| nivel | hechizo |
| ----- | ------- |
| 1     | 1       |
| 4     | 2       |
| 8     | 3       |
| 12    | 4       |
| 16    | 5       |
| 20    | 6       |
|       |         |
