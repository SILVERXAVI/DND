Cuando un jugador o NPC recibe daño es necesario lanzar un dado para saber si ese daño ha causado alguna lesión, por ello se deberá tirar un d20 cuando un jugador sea atacado o ataque a un NPC humanoide，
Si en el dado sale del 1 al 13 el daño no causará ninguna lesión, si sale entre 14 y 17 causara una lesión leve y si sale entre 18 y 20 causara una lesión grave, una vez sabido si el objetivo ha tenido o no una lesión, entonces se volverá a lanzar otro D20 esta vez para determinar en que parte del cuerpo estará la lesión, en este caso si sale entre 1 y10 el daño será en las piernas siendo este los 5 primeros números la pierna izquierda y los 5 últimos la derecha, y si sale entre 11 y 20 el daño se hará en los brazos, siendo estos al igual que las piernas, los cinco primeros el brazo izquierdo y los 5 últimos el derecho.

| D20   | Resultado      | Efecto                                  |
| ----- | -------------- | --------------------------------------- |
| 1-13  | Acierto normal | Daño normal del arma                    |
| 14-17 | Herida Leve    | Aplica penalización leve según la zona  |
| 18-20 | Herida Grave   | Aplica penalización grave según la zona |

| Zona del cuerpo | D20              |
| --------------- | ---------------- |
| 1-5             | Pierna izquierda |
| 6-10            | pierna derecha   |
| 11-15           | Brazo izquierda  |
| 16-20           | brazo derecho    |

---

| Zona    | Tipo       | Efecto                                                            | Obtención                                              |
| ------- | ---------- | ----------------------------------------------------------------- | ------------------------------------------------------ |
| Piernas | Leve       | -1 casilla                                                        | Crítico 14–17 + tirada zona 1–10                       |
|         | Grave      | -2 casillas                                                       | Crítico 18–20 + tirada zona 1–10 o tercer herida leve  |
|         | Mutilación | Movimiento es de 1 casilla                                        | Si recibe 2 graves                                     |
| Brazos  | Leve       | -2 al daño y tirada                                               | Crítico 14–17 + tirada zona 11–20                      |
|         | Grave      | -4 al daño y tirada                                               | Crítico 18–20 + tirada zona 11–20 o tercer herida leve |
|         | Mutilación | No puedes usar el arma o escudo (dependiendo del arma y el brazo) | Si recibe 2 graves                                     |
