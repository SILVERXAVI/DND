## Alma

Peculiaridad, Poco común

Tipo: Emisor

**Descripción:** Alma permite al usuario manifestar una pequeña criatura parecida a un pájaro (ficha de estadísticas abajo) profundamente conectada a su alma. Este pájaro refleja las emociones internas del usuario, dificultándole ocultar sus verdaderos sentimientos. Si bien no posee un poder abrumador, proporciona una valiosa ayuda en diversas situaciones.

**Debilidad:** Si el pájaro queda incapacitado o sus puntos de golpe se reducen a 0, el usuario experimenta una gran carga emocional. Mientras el pájaro esté fuera de combate, el usuario sufre desventaja en todas las tiradas de salvación y de ataque hasta que el pájaro se recupere o el usuario complete un descanso prolongado. Mientras el usuario esté vivo, el pájaro también lo estará y reaparecerá tras un descanso completo.

**Reflejo emocional:** El pájaro del alma muestra claramente las emociones del usuario, imposibilitándole ocultar o mentir sobre sus verdaderos sentimientos. Esto puede servir como elemento de rol, influyendo en las interacciones con los PNJ y otros jugadores. Además, debido a este vínculo, el usuario puede usar su reacción para fintar. El usuario elige una criatura a 9 metros (30 pies) de distancia; tú o un aliado tenéis ventaja en vuestra siguiente tirada de ataque contra esa criatura en este turno. Si el ataque impacta, el usuario añade 2d10 puntos de daño adicionales.

**Acciones de apoyo:** Como acción adicional, el usuario puede ordenar al ave espiritual que realice tareas sencillas, como entregar mensajes o recuperar objetos pequeños a 18 metros (60 pies) de distancia. Alternativamente, el ave puede usar la acción de ataque o realizar una acción de cegar.

- Tiradas de Salvación: Des +7, Int +5

- Idiomas: Común, entiende todos los idiomas del usuario
- Bonificación por competencia: +2
#### Características
- **Diestro/a.** El ave del usuario usa Destreza para sus pruebas de ataque, daño y tiradas de salvación de Fuerza.
- **Cegador/a.** Como acción, el ave del alma del usuario bate sus alas frente al rostro de un oponente, intentando cegarlo. El objetivo debe realizar una tirada de salvación de Sabiduría contra la CD de salvación de la peculiaridad del usuario. Si falla la salvación, el objetivo queda cegado hasta el final del turno actual. Si tiene éxito, el objetivo evita el efecto.
#### Acciones
- **Ataque múltiple.** El Ave del Alma del usuario puede realizar dos ataques con sus garras.
- **Garra.** Ataque con arma cuerpo a cuerpo: +6 al ataque, alcance 18 m, un objetivo. Impacto: 7 (1d4 + 4) de daño cortante.
