## Lavado de Cerebro
Don: Muy Raro
Tipo: Emisor
_**Descripción:**_ El lavado de cerebro permite al usuario someter a un objetivo a un estado de obediencia, obligándolo a seguir sus órdenes verbales. Para activar este poder, el objetivo debe responder verbalmente a algo que el usuario diga. Una vez activado, el usuario puede controlar las acciones del objetivo, quien permanece plenamente consciente de su condición pero incapaz de resistirse.

_**Debilidad:**_ El efecto requiere que el objetivo responda verbalmente. Si el objetivo permanece en silencio o utiliza comunicación no verbal, el don no se puede activar. El usuario solo puede controlar una criatura a la vez; si otro objetivo es sometido al lavado de cerebro, el efecto anterior termina inmediatamente.

**Comando:** Como acción, el usuario puede activar su don durante 1 turno. Durante este tiempo, cualquier criatura que responda verbalmente al usuario queda sujeta a la condición de lavado de cerebro. El usuario puede dar órdenes a un objetivo con Lavado de Cerebro como acción adicional en su turno. Estas órdenes deben ser claras, directas y no exceder una sola frase.

>**Lavado de Cerebro**
Una criatura con Lavado de Cerebro se considera **aturdida**, pero puede moverse a velocidad normal y realizar una acción y una acción adicional si se le ordena. Pierde todo control sobre su cuerpo, y el usuario puede usar una acción adicional para ordenarle que realice cualquier acción, acción adicional o reacción permitida por la Rasgo y el DM, excepto aquellas que le causen daño directo.

>La condición de Lavado de Cerebro termina si ocurre alguna de las siguientes situaciones:
>- El usuario libera voluntariamente al objetivo.
>- El objetivo recibe 50 o más puntos de daño en un asalto.
>- El usuario queda incapacitado o intenta Lavar el Cerebro a otra criatura.
