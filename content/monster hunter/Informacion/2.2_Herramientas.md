**Una herramienta le ayuda a hacer algo que de otro modo no podría hacer, como crear o reparar un artículo, falsificar un documento o abrir una cerradura. Su raza, clase, experiencia o hazañas le brindan competencia con ciertas herramientas. El dominio de una herramienta le permite agregar ventaja a cualquier verificación de habilidad que realice con esa herramienta. El uso de herramientas no está ligado a una sola habilidad, ya que el dominio de una herramienta representa un conocimiento más amplio de su uso. Por ejemplo, el DM podría pedirle que haga una verificación de destreza para tallar un detalle fino con las herramientas de su tallador de madera, o una verificación de resistencia para hacer algo con madera particularmente dura.**

### Descripciones de herramientas PHB
#### Herramientas artesanales
Estas herramientas especiales incluyen los artículos necesarios para dedicarse a un oficio o oficio. La tabla muestra ejemplos de los tipos más comunes de herramientas, cada una de las cuales proporciona elementos relacionados con una sola nave. El dominio de un conjunto de herramientas artesanales le permite agregar su bonificación de competencia a cualquier verificación de habilidad que realice utilizando las herramientas de su oficio. Cada tipo de herramientas artesanales requiere una competencia separada.
#### Conjunto de juegos

Este artículo abarca una amplia gama de piezas de juego, incluidos dados y barajas de cartas (para juegos como Three-Dragon Ante). Aparecen algunos ejemplos comunes en la tabla Herramientas, pero existen otros tipos de juegos. Si domina un juego de juego, puede agregar su bonificación de competencia a las comprobaciones de habilidad que realice para jugar un juego con ese juego. Cada tipo de juego requiere una competencia separada.
#### Instrumento musical

Varios de los tipos más comunes de instrumentos musicales se muestran en la mesa como ejemplos. Si domina un instrumento musical determinado, puede agregar su bonificación de competencia a cualquier verificación de habilidad que realice para tocar música con el instrumento. Un bardo puede utilizar un instrumento musical como foco de lanzamiento de hechizos, Cada tipo de instrumento musical requiere una competencia separada.
#### Kit de disfraz

Esta bolsa de cosméticos, tinte para el cabello y pequeños accesorios te permite crear disfraces que cambian tu apariencia física. El dominio de este kit te permite agregar tu bonificación de dominio a cualquier verificación de habilidad que realices para crear un disfraz visual.
#### Kit de falsificación

Esta pequeña caja contiene una variedad de papeles y pergaminos, bolígrafos y tintas, sellos y lacre, panes de oro y plata y otros suministros necesarios para crear falsificaciones convincentes de documentos físicos. El dominio de este kit le permite agregar su bonificación de dominio a cualquier verificación de habilidad que realice para crear una falsificación física de un documento.
#### Kit de herboristería

Este kit contiene una variedad de instrumentos como cortapelos, mortero y mortero, y bolsas y viales utilizados por los herbolarios para crear remedios y pociones. El dominio de este kit le permite agregar su bonificación de dominio a cualquier verificación de capacidad que realice para identificar o aplicar hierbas. Además, se requiere dominio de este kit para crear antitoxinas y [Pociones de curación](http://dnd5e.wikidot.com/wondrous-items:potion-of-healing).

#### Herramientas del navegante

Este conjunto de instrumentos se utiliza para la navegación en el mar. El dominio de las herramientas del navegante le permite trazar el rumbo de un barco y seguir las cartas de navegación. Además, estas herramientas te permiten agregar tu bonificación de competencia a cualquier verificación de habilidad que realices para evitar perderte en el mar.
#### Kit de envenenador

El kit de un envenenador incluye los viales, productos químicos y otros equipos necesarios para la creación de venenos. El dominio de este kit le permite agregar su bonificación de dominio a cualquier control de habilidad que realice para crear o usar venenos.
#### Herramientas de ladrones

Este conjunto de herramientas incluye una lima pequeña, un conjunto de ganzúas, un pequeño espejo montado sobre un mango de metal, un conjunto de tijeras de hoja estrecha y un par de alicates. El dominio de estas herramientas le permite agregar su bonificación de dominio a cualquier verificación de habilidad que realice para desarmar trampas o abrir cerraduras.
