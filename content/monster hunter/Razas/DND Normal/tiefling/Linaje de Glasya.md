**_Glasya, la mente maestra criminal del Infierno, le otorga magia de atado que es útil para cometer atracos._**

- **Aumento de la puntuación de habilidad.** Tu puntuación de destreza aumenta en 1.

- **Legado de Malbolge.** Ya conoces el cantrip [de la ilusión menor](http://dnd5e.wikidot.com/spell:minor-illusion). Una vez que alcances el nivel 3, puedes lanzar el hechizo [Disfrazarse](http://dnd5e.wikidot.com/spell:disguise-self) una vez como un hechizo de nivel 2. Una vez que alcances el nivel 5, también puedes lanzar el hechizo [de Invisibilidad](http://dnd5e.wikidot.com/spell:invisibility) una vez como un hechizo de nivel 2. Debes terminar un largo descanso para volver a lanzar estos hechizos con este rasgo. El carisma es tu habilidad de lanzamiento de hechizos para estos hechizos.
